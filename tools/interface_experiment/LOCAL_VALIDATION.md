# 本地验证范围

验证日期为 2026-09-16。本地没有 ROS Noetic、Gazebo 或 PPU，不能替代目标服务器运行。

| 检查 | 实际结果 | 能说明的范围 |

| CPU 新网络真实 FP32 前向、反向和 Adam 更新 | 通过 | 本地 CPU 算子可运行 |
| 微型合成夹具上的完整事件/动作训练、验证选择与 checkpoint 恢复 | 通过 | 训练与部署代码链可执行，不说明假设成立 |
| 全部单元检查合计 | 20/20，通过，无跳过 | 同上 |
| 全部新增 Python 的 Python 3.8 语法解析 | 通过 | 语法兼容；不是在 Python 3.8 解释器上的完整运行 |

| Gazebo 相机、UUV 服务、复位及双向跨越 | 尚待服务器验证 | 不宣称能成功跨越或有算法改善 |

本地神经网络检查使用 Python 3.12 与隔离目录中的 PyTorch 2.5.1+cpu。测试依赖没有写入仓库、没有进入部署脚本，也不要求目标服务器安装该版本。目标服务器必须保留部署记录中的 PPU 版 PyTorch 2.0.0a0+nv2303。PPU 可能存在与 CPU 不同的算子实现，因此正式流程会执行新网络的实际更新探测。

本地 CPU 库报告了 cpuinfo/NNPACK 初始化警告，使用 CPU 回退后上述检查完成。这不证明 PPU 或 Gazebo 的性能。

单元测试中的 FixtureEnv、随机图像与短轨迹严格限于 tests 目录，不是实验数据。生产 worker 只能连接真实 ROS/Gazebo，没有自动合成成功数据或自动放宽成功条件的分支。

本实现是一次初步机制验证：使用小 CNN、历史 MLP 和 L1 动作块专家；保留原物理模型并显式记录其局限；所有学生共用同一权重。没有实现 DINOv3、完整 ACT Transformer、flow matching、GRPO、真实 VIO、真实折射或完整基线论文复现。
