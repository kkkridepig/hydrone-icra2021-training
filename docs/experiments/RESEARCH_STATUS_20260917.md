## 候选研究问题与实际实现

候选问题是：当视觉可信度与有效闭环运动响应异步变化时，能否分别估计这两类变化，合理调整观测融合与动作执行时长？研究假设需要在统一专家、观测、预算和任务标准下验证；双头结构、动态 chunk 或模块组合本身不构成已成立创新。

| 已有模块 | 实际含义与边界 |
|---|---|
| 教师采集 | 使用 Gazebo 真值的规则教师，生成双向空水跨越示范；不是成功训练的 SAC |
| 视觉头 | 48×48 RGB 小 CNN，输出高度与视觉退化 logit；未实现 DINOv3 或语言理解 |
| 运动头 | 最近 8 步、每步 19 维历史的 MLP，输出运动扰动 logit |
| 动作专家 | 21 维特征输入、H=4 的三维动作块 MLP；masked L1 是监督损失，不是 L1 自适应控制 |
| 训练损失 | 高度使用 smooth L1，事件使用二元交叉熵，动作块使用带尾部 mask 的 L1 |
| 状态代理 | 加噪仿真 XY/姿态/速度及 IMU；正常学生输入无绝对真值高度，未实现真实 VIO |
| 动作与控制 | 前向/竖直/原桥接航向参考，保持旧动作缩放与航向语义；不是 Lee 的三个增益，Lee 低层闭环持续运行 |
| 调度 | short、long、unified、separated 规则；诊断新增 geometry/oracle 对照，不学习最优执行时域 |
| 冻结诊断 | 复用同一个成功 phase2 模型；不重新训练事件头或专家 |

当前代码没有完整 ACT Transformer、VLA、flow matching 或 GRPO。减少专家查询次数也不等于同幅度降低总计算量、视觉计算或能耗：所有学生每个高层周期仍执行事件模型。

正常学生路径以预测高度、预测风险和传感代理作为输入。真值用于仿真注入、教师与评价；oracle 是明确的特权调度对照，使用当前视觉注入标签与上一已完成区间的施力标签，但仍使用学习高度和原始预测运动风险作为专家条件。它不是全状态最优控制上界。

## 最新冻结诊断的负结果

各策略均为 24 回合，168 回合全部 `crossed=true`。查询数为动作专家总调用数；teacher 不调用学习专家。

| 策略 | 任务成功 | 专家查询 | 平均每回合最大横向偏离（cm） |
|---|---:|---:|---:|
| teacher | 24/24 | 不适用 | 3.78 |
| short | 24/24 | 2303 | 5.82 |
| long | 20/24 | 660 | 9.55 |
| geometry | 20/24 | 1117 | 8.95 |
| unified | 20/24 | 1441 | 8.74 |
| separated | 20/24 | 1403 | 9.04 |
| oracle | 20/24 | 1127 | 8.99 |

20 次失败全部是 seed 201、air_to_water、`height_boundary`，对应五种策略×四工况，clean 也失败。不能把它们视为 20 个独立失败场景。失败出现在界面触发约 31.80–32.11 秒之后，日志支持跨越后的跟踪/持续下潜问题，不能直接称为穿水面瞬间失稳。

separated 相比 unified 查询减少约 2.64%，平均最大横向偏离增加约 3.48%；相比 geometry 查询增加约 25.60%，成功数相同。三个场景种子与一个模型种子不足以形成论文级统计结论，也没有证实 separated 的稳定性优势。

separated 的运动注入窗口召回为 **4/49（8.16%）**，clean 报警为 **214/650（32.92%）**；视觉对应为 72/72 与 2/650。这些分母是相关控制步，标签表示外加扰动时段，不等同于真实动作失效准确率。事件头原来按额外阻尼训练，本次测试有限力脉冲和图像冻结，存在分布与标签语义变化。

mild 按预定顺序入选，教师横向偏离增量约 5.88 cm，峰值倾角增量约 0.0018°；入选不意味着已形成强姿态挑战。不能看完测试结果后换档，再将其包装成未见测试。

## 终止标准与尚未解决的问题

原成功条件要求已经跨界、距目标不超过 0.18 m、速度低于 0.12 m/s、roll/pitch 小于 0.2 rad，并保持 1 秒，随后立即终止。short 的 24/24 证明符合原到达标准，没有证明长期停稳；teacher 也未通过该批记录证明长期保持。

clean/seed201 的 separated 末次决策真值高度约 -1.146 m、估计约 -0.882 m、目标约 -0.707 m，却仍给出约 -0.238 m/s 向下参考。视觉误差与专家终端反馈都需要检查，不能仅靠日志断定唯一根因。补件已提供并核验原权重字节；本地仍没有 torch，未加载 checkpoint、未做反事实模型推理，也未安装普通 torch 替代运行时。

物理边界包括保留的电机系数、浮力/阻尼简化、未验证的水面视觉与有限施力服务语义。真实 VIO、实机泛化、复杂避障、多个训练种子及新场景上的确认性验证均未完成。
